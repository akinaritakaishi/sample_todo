# 社内ツール 画面デザインガイドライン（抜粋）（デモ用ダミーデータ）

> このファイルは勉強会のデモ用に作成した架空の社内文書です。
> 実在する規程・ルールではありません。

## 対象

社内向けに開発・運用する業務ツール全般（タスク管理ツールを含む）

## 3. ステータス・警告表示に関する規定

業務ツール上でユーザーの注意を引く表示（警告・締切・エラーなど）を行う場合、
以下の配色に統一すること。独自の色を追加してはならない。

| 用途 | 色名 | カラーコード |
|---|---|---|
| 緊急・警告（本日中の対応が必要な項目など） | レッド | `#E53935` |
| 注意・確認（近日中に対応が必要な項目など） | オレンジ | `#FB8C00` |
| 通常・情報 | グレー | `#757575` |

## 4. バッジ・ラベルの実装について

- 新規にスタイルを定義せず、既存の表示パターン（テキスト＋背景色の
  シンプルな組み合わせ）に準拠すること
- アイコンを使う場合は絵文字ではなく、意味が伝わるシンプルな図形・記号を推奨
- ラベル内の文言は簡潔にし、装飾的な表現は避けること

## 5. 期限・日付の表記について

- 期限に関する文言は、可能な限り相対表記（例：「本日」「明日」「あと3日」）
  を用いること。絶対日付のみの表記は避ける
- 「本日」「明日」に該当する項目は、上記3項の配色ルールに従って
  視覚的に区別すること

## 6. 適用範囲外の項目

このガイドラインに定めのない表現が必要な場合は、担当チームに確認の上、
本ドキュメントに追記すること。
