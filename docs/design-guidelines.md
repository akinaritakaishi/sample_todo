# デザインガイドライン

`front/`の画面を変更するときに守るデザイン上のルール。色は`front/app/assets/css/main.css`の`:root`で定義したCSS変数（`--color-*`）を使い、コンポーネントに色コードを直接書かないこと。

## 基本の配色

| 用途 | 変数 | 値 |
|---|---|---|
| 背景 | `--color-bg` | `#f4f6f5` |
| カード等の面 | `--color-surface` | `#ffffff` |
| 枠線 | `--color-border` | `#e1e5e3` |
| 本文 | `--color-text` | `#23302c` |
| 補足テキスト | `--color-text-muted` | `#6b7975` |
| アクセント（ボタン等） | `--color-accent` | `#2f8f7a` |
| 完了済み | `--color-done` | `#b7bfbc` |

## 状態を強調するときのルール

注意を引く必要がある状態（期限が迫っている・過ぎているなど）を示す場合は、以下に従う。

1. **色だけで状態を伝えない。** 色覚特性のある人や白黒印刷でも区別できるよう、色に加えて必ず「今日」「明日」のような**テキストのラベル**を併記する。
2. **強調色は次の2段階に限定する。** 変数が`main.css`に未定義なら、下表の値で`:root`に追加してから使う。表にない色を増やす場合は、このガイドラインも同じPRで更新すること。

   | 段階 | 変数 | 文字色 | 背景色 | 使う場面の例 |
   |---|---|---|---|---|
   | 危険 | `--color-danger` / `--color-danger-bg` | `#c62828` | `#fdecea` | 今日が期限・期限切れ |
   | 注意 | `--color-warning` / `--color-warning-bg` | `#a65600` | `#fff4e5` | 明日が期限 |

3. **強調はタスク行の一部（ラベルや左端の線）に留める。** 行全体を塗りつぶすと、一覧の中で強調が多すぎて逆に目立たなくなる。
4. **完了済みのタスクは強調しない。** 期限に関係なく`--color-done`の見た目を優先する。
5. 文字色と背景色のコントラスト比はWCAG AA（4.5:1以上）を満たすこと。上表の組み合わせは満たしている。
