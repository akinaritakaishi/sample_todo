# AI勉強会スライド コンテンツ

このディレクトリは、社内AI勉強会用スライド（`ai-driven-dev-seminar.pptx`）の文言を
1スライド1ファイルのMarkdownで管理するためのものです。デザイン（座標・配色・アイコン）は
`generate/build.js` 側に持たせ、ここには文言だけを置きます。

## ファイル構成

- `01-title.md` 〜 `16-wrap-up.md` … 各スライドの内容（ファイル名の連番がスライド順）
- `generate/` … このMarkdownからPowerPoint（`.pptx`）を生成するNode.jsスクリプト

## Markdownの書式

```markdown
# スライドタイトル

Kicker: スライド上部に表示する短いラベル（省略可）

タイトル直下に表示する導入文・サブタイトル（省略可、プレーンテキスト）

## セクション名（箇条書き）
- 項目1
- 項目2

## セクション名（見出し＋説明の繰り返し）
### 項目タイトルA
項目Aの説明文

### 項目タイトルB
項目Bの説明文

## セクション名（自由文）
1行、または複数行の説明文
```

`##` の後のセクション名は、そのスライドの生成コード（`generate/build.js`）が
参照するキーと一致している必要があります。各ファイルの中身をそのまま真似れば
基本的に崩れません。迷ったら該当ファイルの既存の書き方に倣ってください。

アイコンや色・座標などの見た目はここでは指定しません（`generate/build.js` 側で
スライドごとに固定、または一部は文言から自動判定しています。例：デモの色分け
スライドは「本日／今日」「明日」という語を含むかどうかで赤・オレンジ・グレーを
自動選択）。

## PowerPoint（.pptx）を再生成する

```bash
cd docs/slides/generate
npm install   # 初回のみ
node build.js
```

`docs/slides/generate/ai-driven-dev-seminar.pptx` が生成されます（このファイルと
`node_modules/` はgit管理外です）。

## 内容を修正するときは

1. 該当するスライドの `.md` ファイルを編集する（見出し・箇条書きの構造は変えない）
2. `docs/slides/generate` で `node build.js` を実行して再生成する
3. 生成された `.pptx` をPowerPointで開いて崩れがないか確認する

レイアウトそのもの（配置・色・アイコンの追加など）を変えたい場合は
`generate/build.js` を編集してください。
