# デモ：実務ワークフロー全体をAIが回す

Kicker: Live demo · エンジニア向け

題材：社内タスク管理ツール（本リポジトリ）／Slack連携 + GitHub連携

## ステップ
### Slackの声
「期限が近いタスクが埋もれる」

### Issue化
要望をAIがIssueに整理

### 実装
ブランチ作成〜実装〜PR作成

### セルフレビュー
AI自身が実装の問題点を指摘

### 改善
指摘をもとに同じPRへ再修正

## まとめ帯
Slackの声 → Issue → 実装 → セルフレビュー → 修正まで、一つなぎで実演します

## Notes
Slack投稿は事前仕込み（当日ライブ投稿はしない）。フォーク/専用ブランチでmainを汚さない。
