# AI駆動開発とは

Kicker: AI-driven development

## 本文
- AIを開発プロセスの「中心的な実行リソース」として活用する手法
- 企画・要件定義〜実装・テスト・運用まで、各工程でAIが能動的に生成・提案・検証を行う
- 人間は「意思決定」と「検証」に特化し、プロセスの監督と成果物への最終責任を担う
- 実務作業の多くをAIが肩代わりすることで、人はより本質的な価値創造に注力できる
- 要望を自然文で伝えるだけで、実装だけでなくIssue化・レビュー・修正までを一貫して任せられる
- ただし成果物の質は、事前にAIへ何を渡しているか（仕様・ルール・型）に大きく左右される

## サイドパネル
### 人 × AI
意思決定は人、実装作業の多くはAI。
組み合わせることで開発速度が変わる。
