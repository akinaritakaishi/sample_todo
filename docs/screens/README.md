# 画面仕様書

このディレクトリには、`front/`の各画面（ページ）の仕様を1画面1ファイルで記録する。`docs/pr-screenshots/`がPRごとの動作確認の証跡（履歴）であるのに対し、こちらは「現時点で画面がどうあるべきか」を表す仕様書であり、画面の見た目・挙動が変わるたびに更新する。

## 一覧

- [`tasks.md`](./tasks.md) — ToDo画面（`/`）
- [`chat.md`](./chat.md) — チャット画面（`/chat`）

## 運用ルール

- 画面のUI・挙動に影響する変更（表示項目の追加・削除、操作フローの変更など）を行った場合は、対応する仕様書と、埋め込んでいるスクリーンショット（`<画面名>.png`）を同じPRで更新する。
- スクリーンショットは`docs/screens/<画面名>.png`に直接上書きする（PRごとに履歴を残す`docs/pr-screenshots/`とは別物）。撮影方法は`.claude/skills/verify-front/`を参照。
- 新しい画面を追加した場合は、このファイルの一覧にも追記する。
