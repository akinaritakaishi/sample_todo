# 勉強会デモ2台本：経費精算チェック（非エンジニア向け）

事務の定番作業「申請書と領収書を見比べ、規程と照らし、台帳に転記し、不備があれば本人に連絡する」を、Claude Codeがフォルダ・Excel・チャットをまたいで一続きで処理する様子を見せるデモ。所要時間の目安は約10分。

> 規程・申請書・領収書・人物・店舗・登録番号はすべて**勉強会デモ用の架空のもの**。

## フォルダ構成

```
docs/demo/expense/
  経費精算ルール/   経費精算規程.md・申請書テンプレート.xlsx・通知文テンプレート.md
  10月申請分/       申請1件＝1フォルダ（<申請者>_<内容>_<利用日>）に申請書.xlsxと領収書.pdf
  経理用/           10月申請分_経費台帳.xlsx（見出し行のみ。デモ中に追記される）
  tools/generate.py 上記のExcel・PDFを生成するスクリプト（再生成したいときのみ）
```

「10月申請分」は9月に使った経費を10月1〜5日に申請したもの。フォルダ名の日付は利用日。

## 事前準備

1. `python3 -m pip install openpyxl`（ClaudeがExcelを読み書きするため）。
2. リポジトリルートで`./scripts/demo-up.sh`を実行する（`front/`起動、MCPサーバー`sample-todo-chat`の登録、チャットのシードへのリセット、経費台帳の初期化まで一括）。
3. ブラウザで`http://localhost:3000/chat`を開き、サイドバーの「🧾 経費精算」を選ぶ。経理からの締切案内が1件だけ表示されていることを確認する。
4. `経理用/10月申請分_経費台帳.xlsx`をExcel等で開き、見出し行のみであることを見せられるようにしておく（開いたままだと保存に失敗する環境があるので、デモ中は閉じておく）。

## 進行

1. **（1分）状況説明**：`10月申請分/`のフォルダを見せ、「6件の申請をいつもは経理が1件ずつ目で確認している」と説明する。規程（`経費精算規程.md`）もさっと見せる。
2. **（1分）依頼**：Claude Codeに次のとおり頼む。

   > 10月申請分の経費精算をチェックして

   `expense-check`スキルが使われ、規程を読む → 各フォルダの申請書・領収書を読む → 判定 → 台帳へ転記 → チャットへ通知、と進む様子を見せる。
3. **（5分）結果の確認**：Claudeの最後の報告、台帳、`/chat`の経費精算チャンネルを順に見せる。

## やり直し方

`./scripts/demo-up.sh`を再実行する（台帳が見出し行のみに、チャットがシードに戻る）。サーバーを起動したまま台帳だけ戻す場合は`git restore docs/demo/expense/経理用/`。

## うまくいかないときの手段

- **スキルが使われない**：「expense-checkスキルで10月申請分をチェックして」とスキル名を明示する。
- **`openpyxl`がない**：`python3 -m pip install openpyxl`を実行してからやり直す（Claudeに頼んでもよい）。
- **チャットに通知されない**：`claude mcp list`で`sample-todo-chat`が登録されているか、`front/`が起動しているかを確認する。通知だけ後から「不備のあった人に経費精算チャンネルで連絡して」と頼んでもよい。
- **判定がずれた**：Claudeに「規程の第何条に基づく判定か」を聞き、規程の読み違いを指摘して直させる（それ自体も見せ場になる）。
