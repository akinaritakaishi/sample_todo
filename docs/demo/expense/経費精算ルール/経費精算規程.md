# 経費精算規程（株式会社サンプル研修）

> **勉強会デモ用の架空の規程です。** 実在の会社・社内規程とは関係ありません。

## 第1条（申請）

1. 経費を立て替えた者は、利用月の翌月5日までに所定の申請書（`申請書テンプレート.xlsx`）と領収書を提出して精算を申請する。
2. 申請書と領収書は、申請1件ごとに1つのフォルダ（`<申請者>_<内容>_<利用日YYYYMMDD>`）に格納する。
3. 申請書の金額は、領収書の金額と一致しなければならない。一致しない申請は差し戻す。

## 第2条（領収書）

1. 領収書の宛名は「株式会社サンプル研修」とする。宛名が異なる、または空欄の領収書は差し戻す。
2. 領収書には適格請求書発行事業者の登録番号（`T`＋13桁）が記載されていなければならない。記載がない場合は、経理が支払先に確認するため「要確認」とする。

## 第3条（交通費）

1. 業務上の移動（客先訪問・出張など）に要した電車・バス・タクシー等の実費を精算できる。
2. 申請書の「目的」欄に移動の目的（訪問先など）を記載する。

## 第4条（交際費）

1. 取引先との会食は、参加者1人あたり5,000円（税込）以内とする。参加人数には自社の参加者を含む。
2. 1人あたり5,000円を超える会食は、事前に上長の承認を得て、申請書の「承認者」欄に承認者名を記載しなければならない。承認者の記載がない場合は差し戻す。
3. 申請書の「参加人数」「相手先」欄を記載する。

## 第5条（物品購入）

1. 業務に必要な書籍・備品を購入した場合は、実費を精算できる。
2. 1件あたり10,000円（税込）以上の物品は、事前に稟議の決裁を得なければならない。稟議なしで購入したものは差し戻す。

## 第6条（判定）

経理は申請ごとに次のいずれかで判定する。

| 判定 | 意味 |
|---|---|
| OK | 規程を満たしており、そのまま精算する |
| 要確認 | 経理側で確認が必要（支払先への問い合わせ等）。申請者にも状況を連絡する |
| 差し戻し | 申請者による修正・再提出が必要 |

規程に定めのない事項で判断に迷うものは「要確認」とする。
