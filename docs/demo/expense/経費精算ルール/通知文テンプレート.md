# 通知文テンプレート

> **勉強会デモ用の架空の資料です。**

「差し戻し」「要確認」の申請があった申請者へ、チャットの経費精算チャンネル（`expense`）で通知するときの文面の型。申請者ごとに1投稿にまとめ、該当する申請を箇条書きで並べる。何を直せばよいか（または経理が何を確認するか）と、根拠となる規程の条番号を必ず書く。

## 差し戻し・要確認（共通の型）

```
{申請者}さん
10月申請分の経費精算で、確認が必要な申請がありました。

■ {フォルダ名}（{判定}）
  理由：{理由}（経費精算規程 第{条}条{項}項）
  お願い：{申請者にしてほしいこと}

差し戻しの申請は、修正のうえ同じフォルダへ再提出してください。
ご不明点はこのチャンネルでお知らせください。
```

## 「お願い」欄の書き方

| 判定 | 書き方の例 |
|---|---|
| 差し戻し | 「申請書の金額を領収書（27,440円）に合わせて修正してください」「上長の事前承認を得て承認者欄に記入してください」 |
| 要確認 | 「経理から支払先に登録番号を確認します。対応は不要ですが、登録番号入りの領収書を再発行してもらえる場合はお知らせください」 |
