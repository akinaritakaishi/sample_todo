# ADR 0010: プロジェクトの前提ガイダンスをAGENTS.mdに置き、CLAUDE.mdはそれを読み込むだけにする

- ステータス: 承認
- 日付: 2026-11-03

## コンテキスト

このリポジトリの指示・手順は、今はClaude Codeを使っているためその形式（`CLAUDE.md`・`.claude/`）で置いている。しかしプロジェクトとしては、将来ほかのAIエージェントでも同じ指示で作業できるようにしておきたい。そのため文書の言葉は「AIエージェント」に揃え、製品の名前は製品固有のパスやコマンドを指す箇所だけに使う方針にした（`.claude/rules/agent-config.md`）。

ただ、どのセッションでも前提になる概要（ADR 0001で`CLAUDE.md`に残すと決めたもの）が、Claude Codeしか読まないファイル名の中にある。言葉を汎用にしても、ほかのエージェントからは入口が見えない。

## 決定

- 前提ガイダンスの本体を`AGENTS.md`（複数のAIエージェントが読む共通のファイル名）に移す。
- `CLAUDE.md`は`@AGENTS.md`でそれを読み込むだけのファイルにし、内容を書き足さない。Claude Code固有の指示がどうしても必要になった場合だけ、`CLAUDE.md`の読み込みの下に書く。
- `.claude/rules/`・`.claude/skills/`などは今のまま置く。`AGENTS.md`には、Claude Code以外のエージェントはこれらを自動で読み込まないので、該当するパスを編集する前に自分で読むよう書いておく。

## 検討した代替案

- **`CLAUDE.md`のまま置く**: 変更は要らないが、ほかのエージェントからは入口が見えず、汎用にしたい方針と合わないため不採用。
- **`CLAUDE.md`と`AGENTS.md`に同じ内容を書く**: どちらのエージェントでも読み込めるが、二重管理になり片方だけ更新されて食い違うため不採用。
- **シンボリックリンクで`CLAUDE.md`を`AGENTS.md`に向ける**: 内容は1つで済むが、このリポジトリはWindows（Git Bash）でも使っており、既定の設定ではシンボリックリンクがただのテキストファイルとして展開されるため不採用。
- **`.claude/rules/`・`.claude/skills/`も汎用の場所（`docs/agents/`など）へ移す**: `paths`による読み込みやスキルの自動検出はClaude Codeのこの配置に依存しており、移すと今の動作が失われるため、今回は見送る。

## 結果・影響

- ADR 0001の「`CLAUDE.md`には常に前提となる概要だけを残す」は、`AGENTS.md`に読み替える。ADR 0001で`@path`の読み込みを不採用にしたのは分割ファイルを常時読み込ませたくなかったからで、今回は元から全文を常時読み込んでいる内容をそのまま移すだけなので、コンテキストの消費は変わらない。
- 前提ガイダンスを直すときは`AGENTS.md`を編集する。スキル・ルール・READMEからの参照先も`AGENTS.md`にする。
- ほかのエージェントを実際に使い始めるときは、`.claude/`配下のルール・スキル・権限設定をそのエージェントでどう読み込ませるかを、改めて検討する必要がある。
