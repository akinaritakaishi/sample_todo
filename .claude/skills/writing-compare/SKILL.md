# 文章作成の比較デモ

`docs/demo/writing/`の3つのディレクトリで、同じお題をサブエージェントに書かせて比べる。台本は`docs/demo/writing/README.md`。

## 手順

1. 実行回数`N`を決める（ユーザーの指定がなければ3回）。`docs/demo/writing/*/output*.md`が残っていれば削除する。
2. **1つのメッセージで**Agentツールを`3×N`回呼び、`general-purpose`サブエージェントを並列に起動する。`<dir>`には`plain`・`claude-md`・`rules`、`<n>`には`1`〜`N`を入れ、プロンプトは`<dir>`と`<n>`以外**一字一句同じ**にする（差は指示ファイルと生成の揺らぎからだけ生まれるようにするため。ルールの内容をプロンプトに書き足さないこと）。

   ```
   docs/demo/writing/<dir>/お題.md を読み、お題に沿った文章を書いて docs/demo/writing/<dir>/output-<n>.md に保存してください。docs/demo/writing/ 配下の他のディレクトリのファイルや、他の output-*.md は開かないでください。最後に、文章を書く際に従った指示（どのファイルから読み込まれたか）があれば1〜2行で報告してください。
   ```

3. すべて完了したら`output-*.md`を読み、以下の形で比較を返す。
   - ディレクトリ×回の出力全文（ディレクトリごとにまとめる）
   - ディレクトリ間の比較表（文体・文字数・絵文字の有無・冒頭/末尾の定型文・効いた指示ファイル）
   - 回ごとの揺らぎの表：ディレクトリごとに、文字数の最小〜最大と、各ルールの項目を毎回守れたか（例: 3/3）
   - 一言解説：指示で毎回そろう部分と、毎回変わる部分（言い回し・構成など）。指示のないplainが最も揺らぐか

## 注意

- 出力が期待どおりに分かれなかった場合（例: `claude-md`にルールが効いていない回がある）は、サブエージェントの報告をそのまま示し、指示ファイルが読み込まれなかった可能性として説明する。結果を手で書き直さない。
- `output-*.md`はgitignore対象なのでコミット不要。
