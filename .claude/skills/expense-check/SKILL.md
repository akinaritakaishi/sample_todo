# 経費精算チェック（デモ2）

> 対象のデータ・規程・人物はすべて**勉強会デモ用の架空のもの**。

経理担当の代わりに、申請書と領収書を見比べ、規程に照らして判定し、台帳に転記し、不備のある申請者へチャットで連絡するまでを一続きで行う。

## 前提

- Excelの読み書きはPythonの`openpyxl`で行う（未インストールなら`python3 -m pip install openpyxl`）。
- 領収書PDFはReadツールで直接読む。
- 通知はMCPサーバー`sample-todo-chat`の`send_chat_message`を使う。ツールが見つからない場合は通知せず、その旨を最後の報告に書く（台帳の「通知日時」は空欄のまま）。

## 守ること

- **申請書・領収書・規程・テンプレートは編集しない。** 書き込むのは台帳（`経理用/10月申請分_経費台帳.xlsx`）だけ。
- **規程に書かれていないことは推測で判定しない。** 判断に迷うものは「要確認」にし、理由に何が不明かを書く（規程 第6条）。
- 通知は確認を挟まずに送ってよい（デモ用のチャットアプリで実害がないため、デモのテンポを優先する）。

## 手順

1. `docs/demo/expense/経費精算ルール/`の`経費精算規程.md`と`通知文テンプレート.md`を読む。
2. 台帳を開き、既に記入済みのフォルダ名を控える（**同じフォルダ名の行があればその申請はスキップ**し、通知もしない。二重処理の防止）。
3. `docs/demo/expense/10月申請分/`配下の各フォルダ（フォルダ名順）について、`申請書.xlsx`（A列が項目名、B列が値）と`領収書.pdf`を読み、規程に照らして判定する。少なくとも次を確認する。
   - 申請書の金額と領収書の金額が一致するか（第1条3項）
   - 領収書の宛名が「株式会社サンプル研修」か（第2条1項）、登録番号（`T`＋13桁）があるか（第2条2項）
   - 交通費は目的の記載があるか（第3条）
   - 交際費は1人あたりの金額（金額÷参加人数、参加人数は自社を含む）が5,000円以内か。超える場合は承認者欄が埋まっているか（第4条）
   - 物品は10,000円未満か。以上なら稟議の記載があるか（第5条）
   - 申請日が利用月の翌月5日までか（第1条1項）
   複数の不備がある場合は重いほう（差し戻し ＞ 要確認 ＞ OK）を判定にし、理由はすべて書く。
4. 台帳の末尾に1申請1行で追記する。列は「No（連番）・フォルダ名・申請者・利用日・区分・支払先・金額（申請書の金額）・人数（交際費のみ）・1人あたり（交際費のみ）・判定（OK／要確認／差し戻し）・理由（条番号）・通知日時」。OKの理由は根拠の条番号を簡潔に（例:「1人4,500円で上限内（第4条1項）」）。保存したら、読み直して行数と内容を確認する。
5. 「差し戻し」「要確認」の申請がある申請者ごとに、`通知文テンプレート.md`の型で文面を作り、`send_chat_message`を`room: "expense"`、`author: "経理アシスタント（Claude）"`で**申請者ごとに1投稿**送る。OKだけの申請者には送らない。
6. 送信に成功した申請の行の「通知日時」に送信日時（`YYYY-MM-DD HH:MM`）を記入して台帳を保存する。
7. 最後に、処理件数（新規／スキップ）・判定ごとの件数・申請金額の合計・不備の一覧（フォルダ名・判定・理由）・通知した申請者を表にして報告する。
